# AI Vacation Planner ✈🌍

An AI-based Vacation Recommendation System built using Python, Flask, HTML, CSS, and Machine Learning concepts.

This project suggests the best travel destinations based on user preferences like:

* Travel Type
* Budget
* Preferred Season

The system provides:

* Recommended Destination
* Activities
* Hotel Suggestions
* Travel Mode

* Modern and attractive UI

## Installation ⚙

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/ai-vacation-planner.git
```

### 2. Open Project Folder

```bash
cd ai-vacation-planner
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run Project

```bash
python app.py
```
